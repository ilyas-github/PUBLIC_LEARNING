v2.3 · iOS voice — no Groq needed
Urdu / Arabic voice on iPhone — free Whisper key (2 min, no card)

Apple does not offer Urdu dictation on iPhone, so no code change can make Apple's own voice hear Urdu. This app therefore records your word and sends just that short clip to Groq's free Whisper service, which does hear Urdu and Arabic. Your key stays only in this browser (localStorage) — it is never in the file, and typed search stays fully offline.

1. Open console.groq.com → sign in (Google/GitHub) → API Keys → Create API Key → copy it.
2. Paste it below → Save. Then pick اردو or العربية above and tap 🎤.

No Groq, no key — on-device voice (experimental)

Whisper-tiny runs on your iPhone — audio never leaves the phone, no account, no key. First time it downloads the model once (~43 MB: encoder 10 MB + decoder 31 MB + tokenizer), then it is cached. That first download is the slow part — after that each word takes a few seconds on the phone. Honest limit: tiny is rough for Urdu/Arabic — it can mishear short words. If it mishears, use Groq (accurate) or keyboard dictation (instant) instead.

GitHub-only hosting: put the model files in your repo under models/onnx-community/whisper-tiny/ (see download-whisper-model.sh in the delivery note) and this page will load them from your own GitHub Pages site instead of Hugging Face. GitHub Pages itself cannot transcribe — it is static hosting only, no speech API — so on-device is the only way to have voice with GitHub alone and no other platform at run time.

Keyboard dictation — no key needed, but do this first:
1. iPhone Settings → General → Keyboard → Keyboards → Add New Keyboard → add Urdu and العربية.
2. Back in this app, tap the search box, then tap 🌐 on the keyboard to switch it to Urdu / Arabic — dictation follows the keyboard, not the language dropdown above.
3. Tap the keyboard 🎤 key and speak. Your words appear in the box and search automatically.

Type or say the three letters (“ktb”, “کاف تے بے”, “kay tee bee”), a derived word (الكتاب), or a meaning (“write”, “لکھنا”). For verses: 2:183, 2:1-5, surah 2 or Baqarah shows the ayahs with every word’s root.
