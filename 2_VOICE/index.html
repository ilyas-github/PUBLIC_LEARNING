Needs: Windows PC, Google Chrome (Edge's speech recognition currently returns a "network" error on many PCs — a known Edge problem, not your internet), a microphone, and internet. Read-aloud uses an Urdu voice installed on the PC if there is one; otherwise it automatically uses the online Google Urdu voice. The Voice Test button shows which one will speak. Shortcuts: Ctrl+M = start/stop dictation, Ctrl+S = save, Ctrl+Enter = new paragraph, F8 = read aloud, Esc = stop everything.
